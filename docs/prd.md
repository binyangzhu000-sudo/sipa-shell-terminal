# Требования к приложению

## 1. Обзор приложения

### 1.1 Название и описание
- **Название**: SIPA Shell Terminal
- **Описание**: Веб-приложение для удалённого SSH-подключения с интегрированным AI-ассистентом, обеспечивающее полноценную работу с терминалом через браузер

### 1.2 Целевые пользователи
- Системные администраторы
- DevOps-инженеры
- Разработчики, работающие с удалёнными серверами

### 1.3 Основные сценарии использования
- Удалённое управление серверами через SSH
- Получение помощи от AI-ассистента при работе с командной строкой
- Управление несколькими SSH-подключениями
- Поиск и быстрое подключение к устройствам

## 2. Структура страниц

```
SIPA Shell Terminal
├── Лендинг (/)
├── Терминал (/shell)
├── AI-ассистент (/ai)
├── SSH-подключения (/connect)
├── Поиск устройств (/find-device)
├── Настройки (/settings)
└── Документация (/docs)
```

## 3. Описание страниц и функций

### 3.1 Лендинг (/)

**Назначение**: Представление продукта и привлечение пользователей

**Основные элементы**:
- Героическая секция с кнопкой «Launch Terminal», ведущей на страницу терминала
- 3 карточки с описанием ключевых возможностей приложения
- Футер с дополнительной информацией

**Визуальное оформление**:
- Тёмный фон (#0a0a0a)
- Терминальный зелёный цвет (#00ff41) для акцентов
- Фиолетовые элементы для выделения
- Шрифты: JetBrains Mono для кодовых элементов, Inter для текста интерфейса
- Эффект glassmorphism с зелёным свечением
- Эффект scanline overlay на терминальных элементах

### 3.2 Страница терминала (/shell)

**Назначение**: Основная рабочая область для SSH-подключения и работы с терминалом

**Компоновка**:
- Разделение экрана: 70% — терминал, 30% — AI-панель
- Терминал расположен слева, AI-панель справа

**Функции терминала**:
- Форма подключения к SSH-серверу:
  - Поле ввода хоста (placeholder: «example.com»)
  - Поле ввода порта (placeholder: «22»)
  - Поле ввода логина (placeholder: «username»)
  - Выбор метода аутентификации: пароль или SSH-ключ
  - Поле ввода пароля или текстовое поле для вставки приватного ключа
  - Кнопка «Connect»
- Эмулятор терминала с поддержкой:
  - Ввода команд
  - Отображения вывода команд
  - Интерактивных ссылок в тексте
  - Автоматической подстройки размера под окно браузера
- Статус-бар с отображением состояния подключения
- Панель управления:
  - Кнопка «Reconnect» для переподключения
  - Кнопка «Clear» для очистки экрана терминала
  - Кнопка «Copy» для копирования содержимого терминала
  - Кнопка «Download Log» для сохранения лога сессии в файл

**Функции AI-панели**:
- Отображение последних 20 строк вывода терминала как контекста
- Возможность включения/выключения панели комбинацией клавиш Ctrl+Shift+A
- Стриминг ответов AI-ассистента на основе контекста терминала

**Техническая реализация**:
- Подключение к SSH-прокси через WebSocket
- URL прокси настраивается через переменную окружения VITE_WS_PROXY

### 3.3 Страница AI-ассистента (/ai)

**Назначение**: Взаимодействие с AI-ассистентом для получения помощи

**Функции**:
- Чат-интерфейс для общения с AI
- Отправка сообщений пользователем
- Получение ответов от AI в режиме потоковой передачи
- Использование контекста текущей SSH-сессии (если активна)
- Сохранение и отображение истории переписки

### 3.4 Страница SSH-подключений (/connect)

**Назначение**: Управление SSH-подключениями и ключами

**Функции**:
- Отображение SSH-команды для подключения к приложению
- Кнопка копирования SSH-команды в буфер обмена
- Генерация и отображение QR-кода с SSH-командой
- Информация о публичном SSH-ключе приложения
- Список сохранённых подключений:
  - Отображение названия, хоста, порта, логина
  - Кнопка быстрого подключения для каждого сохранённого подключения
  - Кнопка редактирования параметров подключения
  - Кнопка удаления подключения
- Форма добавления нового подключения:
  - Поле названия (placeholder: «My Server»)
  - Поле хоста (placeholder: «example.com»)
  - Поле порта (placeholder: «22»)
  - Поле логина (placeholder: «username»)
  - Выбор метода аутентификации
  - Кнопка «Save»

### 3.5 Страница поиска устройств (/find-device)

**Назначение**: Поиск и быстрое подключение к устройствам

**Функции**:
- Поле ввода для поиска устройства по имени, IP-адресу или другим параметрам
- Кнопка «Search»
- Отображение результата поиска:
  - Карточка с информацией об устройстве (название, IP, статус)
  - Кнопка «Quick Connect» для мгновенного подключения через SSH
- Таблица известных устройств:
  - Столбцы: Название, IP-адрес, Порт, Статус, Действия
  - Кнопка подключения для каждого устройства
  - Возможность добавления устройства в список сохранённых подключений

### 3.6 Страница настроек (/settings)

**Назначение**: Конфигурация приложения

**Функции**:
- Настройка WebSocket прокси:
  - Поле ввода URL прокси-сервера (placeholder: «ws://localhost:2222»)
  - Кнопка «Test Connection» для проверки доступности
- Настройка API:
  - Поле ввода URL API-сервера (placeholder: «http://localhost:3001»)
  - Информация о fallback на встроенный роут при пустом значении
- Настройка темы терминала:
  - Выбор цветовой схемы
  - Настройка размера шрифта
  - Включение/выключение эффекта scanline
- Конфигурация Cloudflare Tunnel:
  - Поле ввода tunnel ID
  - Поле ввода credentials
  - Инструкции по настройке
- Кнопка «Save Settings» для сохранения изменений

### 3.7 Страница документации (/docs)

**Назначение**: Справочная информация и инструкции

**Разделы**:

  - Шаги установки cloudflared

  - Конфигурация для SIPA Shell Terminal

  - Команды установки зависимостей
  - Команда запуска прокси-сервера на порту 2222

## 4. Бэкенд-сервисы

**Примечание**: Бэкенд запускается отдельно от фронтенд-приложения

### 4.1 WebSocket SSH-прокси
- Прослушивает порт 2222
- Обеспечивает мост между WebSocket-соединениями от браузера и SSH-серверами
- Поддерживает аутентификацию по паролю и SSH-ключу

### 4.2 API-сервер
- Прослушивает порт 3001
- Предоставляет эндпоинты для AI-ассистента
- Поддерживает потоковую передачу ответов AI

## 5. Бизнес-правила и логика

### 5.1 Подключение к SSH
- При нажатии «Connect» устанавливается WebSocket-соединение с прокси-сервером
- Прокси-сервер инициирует SSH-подключение к указанному хосту
- При успешном подключении терминал становится активным для ввода команд
- При ошибке подключения отображается сообщение об ошибке

### 5.2 Работа AI-панели
- AI-панель автоматически получает последние 20 строк вывода терминала
- Контекст обновляется при каждом новом выводе команды
- AI-ассистент использует контекст для формирования релевантных ответов
- При отсутствии активной SSH-сессии AI работает без контекста терминала

### 5.3 Управление подключениями
- Сохранённые подключения хранятся локально в браузере
- При быстром подключении используются сохранённые параметры
- Редактирование подключения обновляет сохранённые данные
- Удаление подключения требует подтверждения

### 5.4 Конфигурация прокси
- Приложение использует URL из переменной окружения VITE_WS_PROXY
- Если переменная не задана, используется значение по умолчанию
- Пользователь может переопределить URL в настройках
- Изменение URL требует перезагрузки страницы терминала

### 5.5 Cloudflare Tunnel
- Поддерживается подключение через Cloudflare Tunnel для безопасного доступа
- Конфигурация tunnel задаётся в настройках
- При использовании tunnel WebSocket-соединения проксируются через Cloudflare

### 5.6 Fallback для AI
- Если VITE_API_URL не задан или пуст, используется встроенный роут для AI
- Встроенный роут работает в режиме preview с ограниченной функциональностью
- При наличии внешнего API используется полнофункциональный AI-сервис

## 6. Исключительные ситуации

| Ситуация | Поведение системы |
|----------|-------------------|
| WebSocket прокси недоступен | Отображение ошибки «Proxy server unavailable», предложение проверить настройки |
| SSH-сервер недоступен | Отображение ошибки «Cannot connect to host», предложение проверить хост и порт |
| Неверные учётные данные | Отображение ошибки «Authentication failed», предложение проверить логин и пароль/ключ |
| Разрыв SSH-соединения | Отображение уведомления «Connection lost», активация кнопки «Reconnect» |
| API-сервер недоступен | Переключение на fallback встроенный роут, отображение уведомления о режиме preview |
| Пустые обязательные поля формы | Подсветка незаполненных полей, блокировка кнопки «Connect» до заполнения |
| Некорректный формат SSH-ключа | Отображение ошибки «Invalid key format» при попытке подключения |
| Превышение лимита сохранённых подключений | Предложение удалить старые подключения перед добавлением новых |

## 7. Критерии приёмки

1. Пользователь открывает лендинг, нажимает «Launch Terminal» и переходит на страницу терминала
2. Пользователь заполняет форму подключения (хост, порт, логин, пароль), нажимает «Connect» и успешно подключается к SSH-серверу
3. Пользователь вводит команду в терминале, получает корректный вывод от сервера
4. Пользователь активирует AI-панель комбинацией Ctrl+Shift+A, видит последние 20 строк вывода терминала в контексте
5. Пользователь переходит на страницу AI-ассистента, отправляет вопрос и получает потоковый ответ от AI
6. Пользователь переходит на страницу SSH-подключений, сохраняет новое подключение, затем использует быстрое подключение из списка
7. Пользователь переходит в настройки, изменяет URL WebSocket прокси, сохраняет изменения и успешно подключается через новый прокси
8. Пользователь нажимает «Download Log» на странице терминала и получает файл с логом текущей сессии

## 8. Функции, не реализуемые в текущей версии

- Многопользовательский режим с системой аутентификации и авторизации
- Совместная работа нескольких пользователей в одной SSH-сессии
- Запись и воспроизведение SSH-сессий
- Интеграция с системами мониторинга и алертинга
- Автоматическое обнаружение устройств в локальной сети
- Поддержка SFTP для передачи файлов
- Кастомизация горячих клавиш
- Экспорт настроек и подключений для переноса между устройствами
- Темы оформления помимо стандартной тёмной
- Мобильная версия приложения
- Интеграция с облачными провайдерами для автоматического получения списка серверов
- Система плагинов для расширения функциональности
- Встроенный редактор файлов
- Поддержка tmux/screen сессий
- Автоматическое переподключение при разрыве соединения
